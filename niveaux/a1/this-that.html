This / that / these / those

Les démonstratifs : montrer ce qui est proche ou loin, au singulier comme au pluriel.

📘 La règle

Les démonstratifs servent à montrer quelque chose. Ils varient selon la distance et le nombre :

  • this (singulier, proche) = ce…-ci : this book (ce livre-ci).
  • these (pluriel, proche) = ces…-ci : these books.
  • that (singulier, loin) = ce…-là : that car (cette voiture-là).
  • those (pluriel, loin) = ces…-là : those cars.

Ils peuvent être suivis d'un nom (this pen) ou s'employer seuls comme pronoms (This is my friend. What's that?).

💡 Bon à savoir

Astuce de prononciation : this (court, i bref) ≠ these (long, « iiz »). Au téléphone, on se présente avec This is… (Hello, this is Tom.).

💬 Exemples

  • This is my phone. Ceci est mon téléphone. (proche)
  • That is your house over there. C'est ta maison là-bas. (loin)
  • These shoes are new. Ces chaussures-ci sont neuves.
  • Those birds are beautiful. Ces oiseaux-là sont magnifiques.
  • Hello, this is Anna speaking. Bonjour, c'est Anna à l'appareil.

⚠️ Erreurs fréquentes

À éviter

  • Dire « this books » : au pluriel c'est these books.
  • Dire « that cars » : au pluriel c'est those cars.
  • Confondre proche et loin : this = ici, that = là-bas.
  • Oublier le verbe : This is a pen, pas « This a pen ».
  • Prononcer this et these pareil : voyelle courte vs longue.

👨‍🏫 Exercices guidés (en classe)

Choisissons le démonstratif ensemble. La réponse est donnée.

  • ___ book (here) → this book proche + singulier
  • ___ shoes (here) → these shoes proche + pluriel
  • ___ mountains (far) → those mountains loin + pluriel
