La quantité : some, any, much, many, a lot of

Exprimer des quantités avec les noms dénombrables et indénombrables.

📘 La règle

On distingue les noms dénombrables (countable : an apple, two apples, on peut compter) et indénombrables (uncountable : water, money, rice, pas de pluriel, pas de « a »).

some / any = « du, de la, des, un peu de » :

  • some dans les phrases affirmatives : I have some bread.
  • any dans les négatives et les questions : I don't have any bread. Do you have any bread?

much / many / a lot of = « beaucoup de » :

  • much + indénombrable (surtout en négation/question) : How much money? Not much.
  • many + dénombrable pluriel : How many books? Too many.
  • a lot of / lots of + les deux, surtout en affirmatif : a lot of water, a lot of friends.

💡 how much / how many

Pour demander la quantité : how much + indénombrable (How much sugar?) et how many + dénombrable pluriel (How many people?).

💬 Exemples

  • There is some juice in the fridge. Il y a du jus dans le frigo.
  • I don't have any money. Je n'ai pas d'argent.
  • How many students are there? Combien d'élèves y a-t-il ?
  • We don't have much time. Nous n'avons pas beaucoup de temps.
  • She has a lot of books. Elle a beaucoup de livres.

🔊 some dans les offres

On utilise some (pas any) dans une question qui est une offre ou une demande polie : Would you like some tea? (« Voulez-vous du thé ? »).

⚠️ Erreurs fréquentes

À éviter

  • Employer some en négation : « I don't have some money » → any.
  • Utiliser much avec un dénombrable : « much books » → many books.
  • Mettre many avec un indénombrable : « many money » → much money.
  • Mettre un pluriel après un indénombrable : « waters, advices » → water, advice.

👨‍🏫 Exercices guidés (en classe)

À faire ensemble. La réponse est donnée pour servir de modèle.

  • I have ___ bread. → I have some bread. Phrase affirmative → some.
  • Is there ___ milk? → Is there any milk? Question → any.
  • How ___ apples? → How many apples? apples est dénombrable → many.
