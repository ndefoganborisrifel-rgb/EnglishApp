Conditionnels (type 3 et mixtes)

Exprimer le regret et l'irréel du passé, et combiner deux temps différents pour relier une cause passée à une conséquence présente.

📘 La règle

Le conditionnel de type 3 (third conditional) parle d'une situation passée et irréelle : on imagine un passé différent de la réalité. Il sert surtout à exprimer le regret ou le reproche.

Structure : If + past perfect, would have + participe passé.

If I had studied, I would have passed the exam. Si j'avais étudié, j'aurais réussi l'examen. (mais je n'ai pas étudié)

Les conditionnels mixtes (mixed conditionals) mélangent deux temps quand la condition et la conséquence ne se situent pas à la même époque :

  • Passé → présent : If + past perfect, would + base verbale.
  • Présent → passé : If + past simple, would have + participe passé.

💡 Bon à savoir

Dans la proposition en would have, on peut remplacer would par could have (aurait pu) ou might have (aurait peut-être) selon la nuance.

🔤 Tableau récapitulatif

💬 Exemples

  • If she had left earlier, she would have caught the train. Si elle était partie plus tôt, elle aurait eu le train.
  • If they had invited me, I would have gone to the party. S'ils m'avaient invité, je serais allé à la fête.
  • If I had saved money, I would be rich now. Si j'avais économisé, je serais riche maintenant. (mixte : passé → présent)
  • If I were more organised, I would not have missed the deadline. Si j'étais plus organisé, je n'aurais pas manqué l'échéance. (mixte : présent → passé)

⚠️ Erreurs fréquentes

À éviter

  • Mettre would dans la proposition en if : on dit If I had known, jamais If I would have known.
  • Oublier le past perfect (had + participe) dans la condition de type 3.
  • Confondre would have et would : would have = passé, would = présent/futur.
  • Écrire would of au lieu de would have (faute due à la prononciation).

👨‍🏫 Exercices guidés (en classe)

À faire ensemble. La réponse est donnée pour servir de modèle.

  • If we had booked earlier, we would have paid less. Type 3 : regret sur le passé (nous avons réservé trop tard).
  • If he had taken the job, he would live in London now. Mixte passé → présent : cause passée, conséquence actuelle.
  • If I spoke German, I would have understood the meeting. Mixte présent → passé : aptitude actuelle, effet sur un événement passé.
