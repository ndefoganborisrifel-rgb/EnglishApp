Conditionnels (type 3 et mixtes)

Exprimer le regret et l'irréel du passé, et combiner deux temps différents pour relier une cause passée à une conséquence présente.

📘 La règle

The type 3 conditional (conditionnel passé) talks about a past unreal situation: we imagine a past different from reality. It is mainly used to express regret or criticism.

Structure: If + past perfect, would have + past participle.

If I had studied, I would have passed the exam.

Mixed conditionals (conditionnels mixtes) combine two different tenses when the condition and the consequence belong to different time frames:

  • Past → present: If + past perfect, would + base form.
  • Present → past: If + past simple, would have + past participle.

💡 Good to know

In the would have clause, you can replace would with could have (ability / possibility) or might have (weaker possibility) depending on the nuance you want to express.

💬 Exemples

  • If she had left earlier, she would have caught the train.
  • If they had invited me, I would have gone to the party.
  • If I had saved money, I would be rich now.
  • If I were more organised, I would not have missed the deadline.

⚠️ Erreurs fréquentes

Common mistakes

  • ❌ If I would have known → ✓ If I had known (never use "would" in the if-clause of a type 3).
  • ❌ If I had know → ✓ If I had known (always use past perfect: had + past participle).
  • ❌ I would had gone → ✓ I would have gone (would have for the past result, would for a present result).
  • ❌ I would of passed → ✓ I would have passed (a spelling error caused by pronunciation — always write have).
