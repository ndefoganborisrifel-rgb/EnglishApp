Les conditionnels (type 0, 1, 2)

Exprimer une condition et sa conséquence : vérités générales, futur réaliste et situations hypothétiques.

📘 La règle

Une phrase conditionnelle a deux parties : la proposition en if (la condition) et la proposition principale (le résultat). L'ordre est libre ; quand if vient en premier, on met une virgule.

Type 0 — vérité générale, toujours vraie : if + présent, présent. If you heat ice, it melts.

Type 1 — condition réelle dans le futur : if + présent, will + verbe. If it rains, I will stay home.

Type 2 — situation hypothétique ou irréelle au présent : if + prétérit, would + verbe. If I had money, I would travel.

💡 Bon à savoir

Au type 2, on emploie souvent were pour toutes les personnes après if : If I were you, I would accept. (Si j'étais toi…). On ne met jamais will/would après if.

🔤 Tableau récapitulatif

Structure des trois conditionnels :

TypeProposition en ifProposition principaleExemple
Type 0 (vérité générale)if + présentprésentIf you mix blue and yellow, you get green.
Type 1 (futur réel)if + présentwill + verbeIf I study, I will pass.
Type 2 (hypothèse irréelle)if + prétéritwould + verbeIf I won the lottery, I would buy a house.

💬 Exemples

  • If you don't water plants, they die. (type 0) Si on n'arrose pas les plantes, elles meurent.
  • If it is sunny tomorrow, we will go to the beach. (type 1) S'il fait beau demain, nous irons à la plage.
  • If I had more time, I would learn the piano. (type 2) Si j'avais plus de temps, j'apprendrais le piano.
  • If I were you, I would apologise. (type 2) Si j'étais toi, je m'excuserais.

🔊 Type 1 ou type 2 ?

Type 1 = c'est possible / probable (If I see her, I will tell her). Type 2 = c'est imaginaire / improbable (If I were rich, I would help).

⚠️ Erreurs fréquentes

À éviter

  • If it will rain, I will stay. → If it rains, I will stay. (pas de will après if)
  • If I would have time… → If I had time… (type 2 : prétérit après if)
  • Confondre type 1 (réel) et type 2 (hypothétique).
  • If I was you → If I were you (forme conseillée au type 2).
  • Oublier la virgule quand la phrase commence par if.

👨‍🏫 Exercices guidés (en classe)

À faire ensemble. La réponse est donnée pour servir de modèle.

  • If you heat water to 100°C, it ___ (boil). → … it boils. (type 0 : présent + présent)
  • If she ___ (study), she will pass. → If she studies, she will pass. (type 1)
  • If I ___ (be) rich, I would travel the world. → If I were rich, I would travel. (type 2)
